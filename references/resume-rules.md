# 简历定制规则

## 总原则

- 只从 `data/profile.md` 的已确认事实中选取，**不新增事实**。
- 针对岗位调整**顺序、篇幅与措辞**，不改变事实本身。
- 一页优先：删重复、合并同类项、把相关经历展开；不靠缩小字号硬塞。
- 不为凑满底部而写套话；也不为省版面删掉一整段真实经历。

## 三种常见岗位怎么调整

### 结构 / 机械 / 机器人

展开：结构方案、三维建模、工程图、样机装配调试、机电配合。
收起：纯理论推导、与岗位无关的课程项目。
注意：参与 ≠ 主导。整车、整机这类成果要写清自己负责哪一部分。

### CAD / 几何 / C++ 研发

展开：几何内核使用、约束求解、特征建模、调试与缺陷修复、构建与测试流程。
收起：纯机械工艺细节。
注意：企业项目与个人项目分开写，不要把公司内核说成开源库，也不要把个人原型说成产品。

### CAE / 仿真分析

展开：前处理、网格质量、边界条件、结果判读、误差与收敛性检查。
收起：与仿真无关的机械工艺。
注意：软件「会用」与「做过求解器开发」是两个层级，别混。

## 共同边界

- 实习与工作经历全部保留（除非明确与岗位完全无关且版面不够，删前先问）。
- 「至今」的日期要按最新确认状态核实，不要自动延长。
- 时间只知道大概就写「硕士阶段 / 本科期间」，不编年月。
- 技能分档：熟练使用 / 用过 / 了解。没有证据的不要写熟练。
- 未确认的工具（如某个 CI、某个求解器特性）不要因为 JD 提到就加上。

## 排版验收

1. 中文 A4 一页；英文按目标市场习惯（一页、带照片或不带照片按当地规范）。
2. 正文可读字号约 10—11pt，行距不压到窒息。
3. 照片比例不变形，不裁到脸。
4. 日期右对齐一致，长英文标题不顶到日期。
5. 字体回退后要重新目检（缺字、字重变化）。
6. 编译两遍 → `pdfinfo` 查页数 → 看每页 PNG → 提取文本核对断词。

## 每个岗位目录应保留

`jd.md`、事实映射、源 `.tex`、PDF、提取文本、预览 PNG、`review.md`、`application.json`、成功凭证截图。文件名带上公司或岗位编号，避免复制别的公司模板时漏改抬头。
