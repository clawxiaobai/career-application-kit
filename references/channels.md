# 投递渠道与操作要点

原则：能用官网就用官网，官方招聘邮箱次之，招聘平台作补充。任何渠道都以**明确成功凭证**为准。

## 企业官网 / ATS

常见流程（Workday、Greenhouse、Lever、北森、Moka 等）：

1. 注册或登录（**必须本人操作**，agent 不代持账号密码）。
2. 上传简历 / 手工填写。
3. 填写个人信息、教育、经历。
4. 自愿披露项（EEO 等，按本人意愿填或跳过）。
5. Review 页面逐项核对。
6. Submit。

注意：

- 学校、专业、公司常是**搜索选择器**，输入文字不等于选中，要确认实际选中的条目。
- 日期控件容易只改年份不改月份，提交前看最终显示。
- 上传成功 ≠ 申请成功。成功依据是「Application Submitted」页面或申请列表里出现该岗位。
- 隐私条款、真实性声明需要**当次确认**，历史同意不延续。

## 官方招聘邮箱

- 收件地址必须来自企业官网或官方招聘公告，不猜、不用第三方汇总。
- 主题建议：`岗位名 / 编号 — 姓名 — 学历与届别`。
- 正文简短，只写与岗位相关的事实，不承诺未知的到岗时间与薪资。
- 附件用**已验收的定制版 PDF**，发送前核对收件人、主题、附件名。
- 保留「已发送」凭证（含收件人和主题）。
- 已发送只证明邮件发出，不保证对方收到或阅读。出现退信要改为 `delivery_failed`，并从成功统计里剔除。
- 邮箱密码、授权码、SMTP 凭据**不写进任何文件**。

## 招聘平台（BOSS / 智联 / 前程无忧 / 猎聘等）

- 优先上传本次定制的 PDF，不要直接让平台用在线简历。
- 有些平台默认展示在线简历，附件效果不同，需确认。
- 未经本人同意，不修改全局在线简历、不同步附件解析、不勾选默认发送。
- 「自动打招呼」可能已经构成一次沟通/投递，不要重复再投。
- 附件库可能有数量上限，删除前先本地备份原件并核对哈希。
- 上传后仍要确认「上传成功」并选中该附件，某些平台上传完还要点确定。

## 遇到这些情况就停

- 验证码、风控、短信验证 → 交回本人。
- 页面状态不明、提交超时 → 先查申请记录，标 `uncertain`，不要连点重投。
- 条款内容有实质变化 → 展示给本人，取得当次确认。
- 登录失效 → 本人重新登录，agent 不保存会话。

## 凭证保存

- 截图存到 `data/history/proofs/` 或对应 job 目录，按内容哈希去重。
- 台账里只记相对路径。
- 截图可能含个人信息与沟通内容，共享前另做脱敏副本。
