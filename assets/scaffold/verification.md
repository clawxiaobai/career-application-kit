# 事实核验记录

用途：记录"这条事实凭什么可信"，避免把猜测写进简历。

## 核验等级

| 等级 | 含义 | 可用于投递 |
|---|---|---|
| A | 本人明确确认，或有证书/成绩单/合同/作品原件 | 是 |
| B | 旧简历或旧材料记载，本人未复核 | 可用，但不得加码 |
| C | 推断、听说、招聘文案暗示 | 否 |

## 核验清单

投递前逐项打勾：

- [ ] 姓名、手机、邮箱与本人当前使用的一致
- [ ] 教育与毕业时间（是否"预计"）正确
- [ ] 每段实习/工作的起止时间与在职状态正确
- [ ] 项目归属：哪些是本人主导、哪些是参与、哪些是团队成果
- [ ] 技能档位与实际使用深度一致（熟练 / 用过 / 了解）
- [ ] 奖项级别与年份正确
- [ ] 没有任何未确认的数字、指标、排名
- [ ] 目标岗位名称与 JD 一致，没有套用其他公司抬头
- [ ] 附件版本是本次定制版，哈希与记录一致
